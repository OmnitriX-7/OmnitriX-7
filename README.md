## 🚀 Featured Projects

### 🚗 [NexRide](https://github.com/OmnitriX-7/NexRide)
> An Uber-like ride-hailing platform with real-time driver matching and live map tracking.

- 🔍 Find drivers within a customizable radius — sortable by **price, proximity & rating**
- 🗺️ Live location tracking via **Mapbox & Leaflet** integration
- ✅ Real-time driver accept/cancel flow powered by **Supabase**
- 💳 In-app payment on ride completion

**Tech:** `React` `TypeScript` `Node.js` `Express.js` `PostgreSQL` `Supabase` `Mapbox` `Leaflet` `Gemini API`

---

### 📝 [IntelliGrade](https://github.com/OmnitriX-7/IntelliGrade)
> AI-powered automated answer sheet grading with blockchain-backed integrity.

- 📄 Professors upload question papers, answer keys & marking schemes
- 🤖 Orchestrated **LLM** evaluates bulk student answer sheets (PDF/image)
- 🔔 Auto-flags questions requiring **human verification**
- 🔗 **Blockchain (Solidity)** ensures tamper-proof marks — any DB change invalidates the record

**Tech:** `React` `JavaScript` `FastAPI` `Supabase` `OpenCV` `Solidity`

---

### 🏫 [Guide-Grid](https://github.com/OmnitriX-7/Guide-Grid)
> A smart coaching centre locator with map-based discovery and direct application support.

- 🔍 Search centres within a **customizable radius** with category-based filtering
- 🗺️ Interactive **Leaflet map** to visualize centre locations
- 📋 Apply directly to any centre through an integrated in-app application form

**Tech:** `Next.js` `React` `TypeScript` `Node.js` `Express.js` `PostgreSQL` `Leaflet` `TailwindCSS`
